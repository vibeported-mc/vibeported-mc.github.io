vibeported.

Unofficial community ports of existing Fabric mods to Minecraft 26.2. Every mod here was written by someone else — we only did the version port.

Not affiliated with the original authors. These are forks published so people can play on 26.2 before official releases exist. All credit for the mods themselves belongs to their authors, linked on each card below. Each fork keeps the original project's licence — check the LICENSE file in its repository. If you are an upstream author and would like a port taken down, open an issue on the relevant repository.

Version numbering

Release tags follow one shape, so a jar always says which mod version and which Minecraft version it is:

<mod version>-<minecraft version>-fabric[-build.<n>]

1.4.7-26.2-fabric-build.0     mod 1.4.7, Minecraft 26.2, first build
0.13.1-26.2.1-fabric          mod 0.13.1, Minecraft 26.2.1, no build counter

Dashes and dots only, never + — a trailing + means "any newer version" to Gradle, and + inside a repository URL path is widely mis-decoded as a space.

Using the Maven artifacts

owo-lib and EMI are also published as Maven artifacts to this organisation's GitHub Packages, which is how Alloy Forgery consumes them.

A token is required, even though everything here is public. GitHub Packages' Maven registry rejects unauthenticated reads with 401 regardless of visibility. You need a personal access token with the read:packages scope (gh auth refresh -h github.com -s read:packages, or a classic PAT). The jars on the Releases pages need no token at all — prefer those if you just want to play. 
repositories {
    maven {
        url = "https://maven.pkg.github.com/vibeported-mc/owo-lib"
        credentials {
            username = System.getenv("GITHUB_ACTOR")
            password = System.getenv("GITHUB_TOKEN")
        }
    }
}

dependencies {
    modImplementation "io.wispforest:owo-lib:0.13.1-26.2-fabric-build.0"
    compileOnly       "dev.emi:emi-fabric:1.1.24-26.2-fabric-build.0"
}
